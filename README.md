# PAI – Projektowanie Aplikacji Internetowych

Repozytorium zawiera projekty realizowane w ramach przedmiotu **Projektowanie Aplikacji Internetowych**.

## Struktura repozytorium

```
PAI/
├── projekt1/   # Pierwszy projekt (HTML, CSS, JavaScript)
├── projekt2/   # Drugi projekt
└── ...
```

## Technologie

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js / Express (backend)

## Uruchamianie projektów

Każdy projekt zawiera własny plik `README.md` z instrukcją uruchomienia.
